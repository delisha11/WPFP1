# Portfolio – Delisha Ashruf

Persoonlijke portfoliosite voor WPFW Opdracht 1 van de HBO-opleiding ICT aan De Haagse Hogeschool.

## Pagina's

* **Whoami** – informatie over mij en mijn vaardigheden
* **Projecten** – overzicht van mijn projecten
* **Blog** – mijn ervaringen en informatie over ICT

## Gebruikte technieken

* HTML5
* CSS3
* Responsive design
* Git & GitHub

De website bestaat uit drie samenhangende HTML-pagina's met een gedeelde CSS-stylesheet.
